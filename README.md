# 살아있는 공룡박물관 4DX

사진 기반 백악기 전시관 4개와 GLB 3D 공룡 모델 11개를 사용하는 브라우저 체험입니다.

## 이번 수정

- 모든 전시관의 공룡을 사진 중앙의 관찰 영역에 배치합니다. 전시관마다 공룡 위치를 독립적으로 관리하며, 이전의 월드 좌표(-40, 40, 80)를 사용하지 않습니다.
- 제1관 **시간의 문**: 트리케라톱스와 스테고사우루스 **2마리**를 입구 중앙에 배치합니다. 다른 전시관에서도 재사용하는 모델이며 별도의 GLB 파일을 추가하지 않습니다.
- 제2관 **초식공룡의 숲**: 브라키오사우루스, 트리케라톱스, 스테고사우루스, 브론토사우루스, 프로토케라톱스 **5마리**.
- 제3관 **포식자의 계곡**: 티라노사우루스, 프테라노돈(익룡), 바스타토사우루스(가상 공룡), 티라노사우루스 실감 특별전 **4개 모델**.
- 제4관 **멸종의 순간**: 트리케라톱스 특별전, 티라노사우루스 특별전 **2마리** 및 운석 충돌 체험.
- 전시관 버튼의 활성 상태와 선택된 공룡 카드의 강조 표시를 강화했습니다.
- 공룡을 클릭하면 선택되고, 공룡 위에서 드래그하면 그 모델만 회전합니다. 빈 배경에서 드래그하면 카메라가 회전합니다.
- 기존 배경 PNG 4개와 음성 안내·효과음·화면 진동을 유지합니다.

## 파일 구조

`index.html`, `README.md`는 저장소 최상위에, GLB 11개는 `assets/`, 배경 PNG 4개는 `assets/backgrounds/`에 둡니다.

## 사용법

GitHub Pages에서 실행한 뒤 왼쪽의 전시관 버튼을 선택합니다. 하단 공룡 카드를 클릭하면 해당 공룡으로 카메라가 이동합니다. 공룡 자체를 드래그하면 개별 회전하며, 빈 공간을 드래그하면 전체 시점을 바꿀 수 있습니다.

## 한계와 유의사항

배경은 2D 사진입니다. 카메라를 크게 회전하면 3D 공룡과 배경의 원근이 완벽히 일치하지 않을 수 있습니다. 공룡의 발과 사진 속 지면의 정확한 일치는 브라우저와 GLB 모델별로 추가 조정이 필요합니다. 실제 GLB 11개의 브라우저 동작은 아직 현장 검증 전입니다. 모델별 저작권 및 라이선스를 확인하세요.
