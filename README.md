# 살아있는 공룡박물관 4DX — 개별 움직임 개선 v3

사진 기반의 전시관 4개와 GLB 공룡 모델을 이용한 브라우저 체험입니다.

## v3 개선 내용

- **빈 공간 드래그:** 카메라 회전을 비활성화했습니다. 다른 공룡이 함께 움직이는 듯한 현상을 방지합니다.
- **공룡 위 드래그:** 마우스로 잡은 공룡 **한 마리만** 좌우 회전합니다. 다른 공룡의 회전 각도는 바뀌지 않습니다.
- **공룡별 자동 움직임:** 모델마다 서로 다른 주기·위상·이동 폭으로 작은 범위에서 독립적으로 움직입니다. 공룡의 실제 보행 동작은 각 GLB에 포함된 애니메이션의 유무에 따라 달라집니다.
- **공룡 카드 클릭:** 해당 공룡만 선택하고 설명을 갱신합니다. 클릭만으로 카메라가 움직이지 않습니다.
- **마우스 휠:** 확대/축소가 가능합니다. 오른쪽 '가까이 관찰' 버튼은 선택한 공룡으로 시점을 이동합니다.
- **전시관 전환:** 전시관별 배경과 공룡 구성을 유지하고 카메라를 해당 전시관 기본 위치로 복귀시킵니다.
- 사진 배경 4장, 효과음, 음성 안내, 진동 및 운석 충돌 기능을 유지합니다.
- 제2관의 프로토케라톱스 화석 모델은 전시하지 않습니다. 기존 GLB는 삭제할 필요 없습니다.

## 조작

| 조작 | 결과 |
|---|---|
| 공룡 직접 드래그 | 해당 공룡만 회전 |
| 빈 배경 드래그 | 카메라 및 공룡 배치 유지 |
| 공룡 카드 클릭 | 해당 공룡 선택 및 설명 |
| 마우스 휠 | 카메라 확대/축소 |
| 가까이 관찰 | 선택 공룡으로 카메라 이동 |
| 시점 초기화 | 전시관 기본 시점 복귀 |

## 주의사항

배경은 2D 사진이고 공룡은 별도 WebGL 3D 레이어입니다. 공룡별 이동은 사진 위에서 제한된 범위로 표현되며 실제 3D 지형을 걷는 시뮬레이션은 아닙니다. GLB에 애니메이션이 없는 공룡은 모델 전체가 부드럽게 이동·회전하는 방식으로 표현됩니다. 모델의 저작권과 사용 라이선스는 별도로 확인해야 합니다.
