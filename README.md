# 살아있는 공룡박물관 4DX — v7 충돌 후 지형 윤곽 개선

## 수정 사항
- 제4관 운석 충돌 후 기존 녹색 사진 배경에 흑백·옅은 갈색 필터를 적용하되 밝기를 높여 나무·산·바위·지표 윤곽이 보이게 조정했습니다. 지나치게 검었던 전면 덮개와 연무의 불투명도를 낮추고 분화구는 유지합니다. **사진의 나무 형태를 실제로 태우거나 삭제하는 3D 지형 변경은 아닙니다.**
- 제4관의 공룡이 한 마리일 때 하단 명판을 내용에 맞게 축소합니다. 충돌 후에는 공룡 명판을 숨깁니다.
- 제2관의 `숲속 발걸음`을 `가까이 관찰`로 바꾸고, 누르면 선택 공룡 한 마리만 확대합니다.
- 제3관의 `포효 체험`을 `가까이 관찰`로 바꾸고, 포효 효과음을 사용하지 않습니다.
- 공룡을 선택하지 않았을 때에는 해당 전시관에서 첫 번째로 표시된 공룡을 자동 선택하여 확대합니다.
- 개별 공룡 회전 및 마우스 휠 개별 확대·축소, 4개 전시관의 사진 배경, 운석 충돌 기능을 유지합니다.

## GitHub 반영
`imm-content/dinosaur-museum-4dx` 저장소 루트에 `index.html`, `README.md`를 업로드하여 기존 파일을 교체하십시오. `assets/`의 기존 GLB 및 배경 PNG는 그대로 둡니다.

## 주의
사진 위에 표현하는 2D 연출이므로 실제 나무가 쓰러지거나 불타 없어지는 물리 시뮬레이션은 아닙니다. JavaScript 구문 검사는 통과했지만 GitHub Pages 브라우저 실동작은 배포 후 확인해야 합니다.
