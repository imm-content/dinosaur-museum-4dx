# 살아있는 공룡박물관 4DX — v5

## 제4관 멸종의 순간 수정
- 표시되지 않던 티라노사우루스 특별전 카드 및 모델 배치를 제거했습니다.
- 트리케라톱스 특별전 공룡을 화면 중앙으로 이동하고 기본 모델 크기를 확대했습니다.
- 운석 충돌 버튼은 공룡 선택 여부와 관계없이 **운석 충돌** 기능을 유지합니다.
- 공룡 선택 시 **가까이 관찰** 버튼을 별도로 표시하며, 해당 버튼은 운석을 발생시키지 않고 공룡 모델 자체를 확대합니다.
- 충돌 시 공룡이 사라지고, 배경 위에 분화구·그을음·연기가 남습니다. 사진 배경 자체를 수정하는 것이 아닌 2D 시각효과입니다.
- 전시관 재입장 및 시점 초기화 시 충돌 이전 상태로 복원됩니다.

## GitHub 적용
저장소 루트의 `index.html`과 `README.md`를 업로드하여 교체합니다. `assets/` 폴더는 유지합니다.

## 유의 사항
기존 사진은 평면 이미지이므로 분화구는 사진 위에 덧그린 시각적 연출이며, 실제 3D 지형 변형은 아닙니다. 실제 브라우저 검증은 별도로 필요합니다.
