# 살아있는 공룡박물관 4DX — 공룡별 독립 확대·축소 v4

## 이번 수정의 핵심

이전 버전의 `OrbitControls.enableZoom=true` 때문에 마우스 휠을 돌리면 카메라가 앞뒤로 이동하면서 화면의 공룡 **모두가 동시에** 확대·축소되었습니다. v4에서는 카메라 휠 줌을 끄고 **선택된 GLB 공룡 객체의 `scale`만** 변경합니다.

| 조작 | 결과 |
|---|---|
| 공룡 A 클릭 | A 선택, 설명과 카드 강조 |
| 공룡 A 위에서 휠 위/아래 | A만 확대/축소, B는 그대로 |
| 공룡 A 선택 후 빈 배경에서 휠 | A만 확대/축소, B는 그대로 |
| 공룡 B 클릭 후 휠 | B만 확대/축소, A의 크기는 유지 |
| 공룡 드래그 | 잡은 공룡만 좌우 회전 |
| 빈 배경 드래그 | 아무 공룡도 회전하지 않음 |
| 시점 초기화 | 공룡별 크기를 100%로 되돌리고 기본 카메라 위치 복귀 |

- 공룡 크기는 기본 크기의 **40%~280%** 범위로 제한합니다.
- 각 공룡의 확대 배율은 독립적으로 저장되며 전시관을 바꾸었다 돌아와도 유지됩니다. `시점 초기화`를 누르면 모두 원래 크기로 복원됩니다.
- 선택하지 않은 상태에서 빈 배경에 휠을 돌리면 먼저 공룡을 선택하라는 안내를 표시합니다.
- GLB 원본의 기본 크기 정규화는 유지하며, 개별 크기 변경은 바깥 `pivot` 그룹에만 적용합니다.
- 기존 4개 백악기 사진 배경, 공룡 전시 구성, 개별 회전, 포효, 음성, 운석, 진동 기능은 유지합니다.
- 제2관에서 프로토케라톱스 뼈 모델은 제외된 상태입니다.

## GitHub 적용

`imm-content/dinosaur-museum-4dx` 저장소의 최상위에 `index.html`과 `README.md`만 교체하여 업로드하십시오. `assets`의 GLB와 `assets/backgrounds`의 PNG는 수정할 필요 없습니다. 반영 후 `Ctrl+F5`로 새로고침하십시오.

## 확인할 사항

제1관에서 트리케라톱스를 선택하고 빈 배경 위에서 휠을 돌렸을 때 트리케라톱스만 커져야 합니다. 이후 스테고사우루스를 선택해 휠을 돌리면 스테고사우루스만 커지고 트리케라톱스의 크기는 유지되어야 합니다.

브라우저의 실제 GLB 렌더링 및 모든 입력 장치에서의 동작은 배포 후 확인이 필요합니다.
